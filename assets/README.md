# 贴图与动画 / v0.2

## 桌宠基础形象

`pets/pet-0.png` 至 `pet-5.png` 按用户提供的六宫格图片顺序裁切，分别对应早八鹅、炸毛鹅、充鹅不闻、轻鹅易举、鹅累了、等放假鹅。统一画布为 320 × 384，PNG 透明背景，脚底基准接近 y=374。

这些是用户提供图片的抠图版本，并非 AI 新生成或从零原创。保留原图主体、耳罩、被子与服装，移除原图背景和图下标题。原图分辨率有限，毛绒轮廓仍有轻微浅色边缘。`pet-roster.png` 为六款基础形象总览。

运行时采用贴图整体位移、轻微旋转和待机起伏的二维动画：待机、行走、拿工具工作、休息、喂食和陪伴。不是骨骼绑定或三维模型。

复现抠图：使用 .NET Framework C# 编译器编译 `tools/PreparePets.cs`，传入参考图路径与输出目录。背景从边缘连通区域移除，主体内部白色腹部保留。

## 工具

`tools/` 包含蟑螂拍、扫把、拖把、蟑螂药与喷雾的单帧透明贴图及八帧动画图集。原始可编辑绘制模型在 `src/Art.cs`，与现有 WPF 二维游戏绘制保持一致。

- `swatter-strip.png`：拍下、回弹。
- `broom-strip.png`：左右挥扫。
- `mop-strip.png`：拖洗、布条摆动。
- `bait-strip.png`：诱饵盒投放起落。
- `spray-strip.png`：喷雾粒子变化。

每张图集为 1280 × 160，每帧 160 × 160，八帧从左到右排列，背景透明。游戏在 0.45 秒内播放工具动作；桌宠工作动作约 0.65 秒。图标使用第 0 帧。运行时缓存相同模型生成的位图，六款桌宠基础 PNG 内嵌进 exe。

重新导出工具贴图：

```powershell
.\bin\DesktopRoach.exe --export-assets assets\tools
```

本轮未调用 AI 图片生成工具。已读取 imagegen 技能，当前环境没有内置 image_gen；未调用需额外授权的 API 备用方案。
